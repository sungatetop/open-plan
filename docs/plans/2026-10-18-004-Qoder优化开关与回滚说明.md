> **本批范围：** P0 层四项 + P2 层全部六项 + P1 层两项（P1-5 服务端流配额与 `Retry-After` / P1-2 事件负载结构校验），**共 12 项全部默认关闭**。P1 的其余六项（执行句柄契约 / 先订阅后发送 / 交互 owner / 陈旧流停摆 / 令牌三层化 / 右侧对象栏）见 §七 的评估结论。

## 一、三层回滚（按粒度从细到粗）

### 第 1 层：运行开关即时回滚（推荐，秒级）

本批所有改动都由**运行开关**控制，且**默认全部关闭**——也就是说：

> **你什么都不做，跑的就是优化前的基线行为。**

要回滚，只需让开关保持关闭（或把已设的环境变量去掉）：

```powershell
# 关闭整族（推荐：一键回到基线）
Remove-Item Env:OAW_QODER_ALIGN -ErrorAction SilentlyContinue
Remove-Item Env:OAW_QODER_STYLE -ErrorAction SilentlyContinue
Remove-Item Env:OAW_QODER_SSE_BACKOFF -ErrorAction SilentlyContinue
npm start        # 重启服务，开关重新读取
```

> **注意（重要）：** 服务端开关遵循本项目既有约定 —— `RUNTIME_FLAGS` 在**模块加载时解析一次**（服务生命周期内不热更），前端经 `/api/status` 的 `runtimeFlags` 快照读取。因此**改环境变量后需要重启服务**；前端在下次页面加载时生效。

### 第 2 层：单文件回滚

只想退掉某一个文件的改动：

```bash
git checkout backup/pre-qoder-align-20261018 -- client/src/styles.css
git checkout backup/pre-qoder-align-20261018 -- client/src/App.jsx
git checkout backup/pre-qoder-align-20261018 -- client/src/components/ChatPanel.jsx
git checkout backup/pre-qoder-align-20261018 -- server/运行开关.mjs
```

> 该命令只覆盖指定文件，**不影响工作区里其它未提交的改动**（含你原有的那些修改）。

### 第 3 层：整站回滚

```bash
# 安全做法：先把当前所有未提交改动（含你原有的）存起来，再切回基线
git stash push -u -m "回滚前暂存"
git checkout backup/pre-qoder-align-20261018

# 想回到刚才的状态
git checkout master && git stash pop
```

```bash
# 激进做法（会丢弃工作区全部未提交改动，谨慎！）
git reset --hard backup/pre-qoder-align-20261018
```

**回滚锚点：** 标签 `backup/pre-qoder-align-20261018`，指向提交 `1b17294e`（v0.11.55，优化前的完整基线）。

## 三、怎么开启预览

```powershell
# ① 只预览视觉（整站换成中性灰阶 + Nord 冷蓝 + 统一语义三色）
$env:OAW_QODER_STYLE = "1"
npm start

# ② 只开启重连退避优化
$env:OAW_QODER_SSE_BACKOFF = "1"
npm start

# ③ 只开启对话流背压（服务端行为，界面无变化）
$env:OAW_QODER_SSE_BACKPRESSURE = "1"
npm start

# ④ 只开启中断排空（服务端行为，界面无变化）
$env:OAW_QODER_DRAIN_ON_ABORT = "1"
npm start

# ⑤ 只开启视觉特效降级（去背景模糊与长动效）
$env:OAW_VISUAL_EFFECTS_OFF = "1"
npm start

# ⑥ 只开启服务端流配额（超限返回 503 + Retry-After）
$env:OAW_STREAM_QUOTA = "1"
npm start

# ⑦ 只开启事件负载校验（只告警 + 计数，不改变行为）
$env:OAW_EVENT_SCHEMA_CHECK = "1"
npm start

# ⑧ 只开启右栏对象栏（第三页签：产出 / 来源 / 技能 / 记忆 / 后台）
$env:OAW_QODER_OBJECT_BAR = "1"
npm start

# ⑨ 只开启领域工作流声明层与只读面板（/api/workflows 追加只读 domain 字段；预检端点开放）
$env:OAW_DOMAIN_WORKFLOWS = "1"
npm start

# ⑩ 只开启超大工具输出单帧切分（服务端行为，界面无变化）
$env:OAW_QODER_TOOL_OUTPUT_SPLIT = "1"
npm start

# ⑪ 只开启交互归属标签（服务端下发归属 + 前端卡片显示「来自…」）
$env:OAW_QODER_INTERACTION_OWNER = "1"
npm start

# ⑫ 整族一次性开启
$env:OAW_QODER_ALIGN = "1"
npm start
```

开启视觉层后可自查这几点（对齐对标报告 §3.4 视觉自检清单）：

- 底色由蓝紫 `#1a1a2e` 变为中性 `#111111`，面板 `#141414`
- 强调色由青绿 `#8abeb7` 变为冷蓝 `#81a1c1`
- 语义色统一为 绿 `#3fa266` / 红 `#e34671` / 琥珀 `#f1b467`
- 分隔线由实色灰 `#3a3a5c` 变为低透明度前景色 `#f0f0f01a`
- 暗/亮两套主题均生效；关掉开关后外观立刻回到原样

## 五、为什么这样改是安全的（不碰核心）

1. **只加不改**：4 个文件全部是「新增」或「文件末尾追加」，没有删除、重写、重排任何既有逻辑或规则。
2. **默认关**：开关关闭时走的就是原基线分支——`computeRetryDelay()` 的第一行 `if (!flag("qoderSseBackoff")) return Math.min(5000, retryDelay * 2);` 就是原来的那行公式，逐字未变。
3. **视觉零残留**：令牌层用 `:root[data-oaw-style="qoder"]` 做**变量覆盖**，不删不改任何旧变量；移除该属性即完全还原，无需清理样式、无死代码。
4. **不碰核心资产**：未改事件注册表、执行句柄、运行预算、子代理契约、成果验收、Pi 接入、文档引擎、地图模块；未新增任何事件类型；未改任何 API 形状与响应结构。
5. **可审计**：三层回滚 + 全部改动集中在 4 个文件，`git diff` 一次看全。
