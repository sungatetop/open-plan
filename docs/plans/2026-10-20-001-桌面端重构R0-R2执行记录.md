# 桌面端重构 R0-R2 执行记录

## R1 等价壳（2026-10-20 完成，冒烟通过）

进程模型（过渡形态）：

```
Electron main（electron/src/main/）
├─ index.ts        生命周期：单实例锁 / 窗口托管 / before-quit 收尾 / smoke 通道
├─ splash.ts       启动窗口（本地 splash 页，sandbox+contextIsolation，外链转系统浏览器）
├─ legacy-server.ts  spawn process.execPath + ELECTRON_RUN_AS_NODE=1 运行 server/index.mjs
│                    （仅 127.0.0.1，PORT 自动选 3002-3099，日志环形缓冲 200 行）
├─ util/port.ts    端口探测与顺延（5 项单测）
├─ util/wait.ts    /api/status 就绪轮询（3s 超时步进，120s 总窗）
└─ preload         contextBridge 暴露 opDesktop v1（getServerStatus/onServerStatus）
```

- 启动流程：ready → 选端口 → splash → spawn 旧 server → `/api/status` 就绪 → `loadURL(http://127.0.0.1:<port>/)`（服务端直接伺服 client/dist，旧前端全功能可用）
- 失败路径：spawn 退出 / 就绪超时 → splash 显示错误与日志尾部；smoke 模式输出 `SMOKE_FAIL`
- 退出路径：window-all-closed / before-quit → taskkill /T /F（win）或 SIGTERM→SIGKILL（5s 兜底）
- **冒烟证据**：`npm run desktop:smoke` → `SMOKE_OK port=3003`（3002 被常驻服务占用时端口顺延逻辑同时得到验证）

## R2 协议基座（2026-10-20 完成）

- `electron/src/shared/desktop-protocol.ts`：桌面平台协议 v1（ServerStatusPayload）
- `electron/src/shared/protocol/event-registry.ts`：**115 种事件注册表 TS 化**——`EventType` 字面量联合类型、`as const satisfies readonly EventSpec[]` 编译期约束 persist⇒lifecycle、类型化 `byType` 索引、`validateEventPayload` 纯函数语义一致
- `electron/src/shared/runtime/`：**B1 纯函数域 9 个模块全量 TS 化**（server 同名 .mjs 逐函数等价迁移）：

| 模块 | 关键导出 | 对拍要点 |
|---|---|---|
| run-trace.ts | normalizeCompletion / applyObjectiveDowngrade / inferCompletion | 完成语义归一化矩阵 |
| turn-budget.ts | turnNoticeKind / turnNoticeText / turnBudgetPolicy | 25/45 轮与周期播报优先级 |
| event-normalization.ts | normalizePiEvent / canonicalFromEnvelope / assertCanonicalShape | 未登记类型 `pi.<t>` 透传（空串回退 `pi.unknown` 与 JS 真值语义严格一致） |
| event-protocol.ts | createStreamId / resolveReplayCursor / pushChannelEvent / isHistoryTruncated | 语义化淘汰（增量先于生命周期被逐出）逐 id 序列对照 |
| run-budget.ts | stableStringify / fingerprintArgs / evaluateToolGate / evaluateTurnGate / grantBudget 等 | 轮询放行、重复无进展、连续失败、软/硬预算、加预算重置全序列 |
| task.ts | normalizeTaskMode / toolPolicyForMode / planTaskCapabilities / createTaskEnvelope / taskSummary | 四模式白名单、意图矩阵（office 生成 vs 编辑分流、地图读写路由）、信封默认值 |
| feature-flags.ts | RUNTIME_FLAGS / runtimeFlagsSnapshot | env 加载时解析：QODER_ALIGN 总开关派生、非法数值回退、白名单切分归一；env 清空重载后再对拍 |
| first-token-latency.ts | markRunTiming / finishRunTiming / mergeClientTiming / percentile / latencySummary | 两种结算顺序落同一样本、非法 span 丢弃、P50/P95 口径（样本时间戳剥离后逐字段对照） |

- 对拍结论与教训：
  - `canonicalTypeFor("")` 首轮对拍暴露 TS `??` 与 JS `||` 回退语义差异，已按 JS 真值语义修正（`Boolean(piType) ? String(piType) : "unknown"`）
  - event-protocol 对拍首轮两侧事件流 id 前缀不同导致假失败，修正为同前缀同流输入
  - `finishRunTiming` 仅客户端打点也可结算成样本（firstEventAt 属合法阶段），对拍用例按此口径修正
- `event-storage.mjs` **不迁入 B1**：fs/EventEmitter/文件锁 IO 重度模块，随 R3 事件域整体迁移
