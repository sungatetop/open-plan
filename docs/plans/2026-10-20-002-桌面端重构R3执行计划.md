# 桌面端重构 R3 执行计划（对话链路）

依据 `docs/solutions/2026-10-19-Electron一体化TypeScript重构方案.md` §4.3/§5/§6。R2（协议基座 + F1 纯函数域）已于 2026-10-20 收口，进入 R3（最大风险点，单独排期、充分冒烟、冻结域内新功能）。

## 目标与验收门槛（方案 §6）

- 内容：F2 应用骨架（F3 的前置）+ F3 chat 域（新 renderer 首个域）+ B6 agent/pi 域 TS 化
- 门槛：新界面完成一次完整 Agent 任务（含审批/产物/结论卡），事件协议 diff 为空
- 约束：`OP_DESKTOP_NEW_UI` 等 flag 默认关（BRD-003）；默认路径行为不变（仍加载旧 client）

## 领域目录约定（F2 确立，后续域照此落位）

| 目录 | 职责 |
|---|---|
| `electron/src/renderer/app/` | 应用入口与骨架（main.tsx / App.tsx / theme.tsx / 多页 app.html） |
| `electron/src/renderer/api/` | IPC 通道封装（对齐 `shared/protocol` 通道族，禁止新代码引入 HTTP/SSE） |
| `electron/src/renderer/features/<domain>/` | 领域组件（chat/task/doc/map/kb/workspace/settings/market…） |
| `electron/src/renderer/lib/` | 纯函数模块（F1 已收口 20 个） |
| `electron/src/renderer/components/` | 跨域通用组件 |

## 分批实施

| 批次 | 内容 | 验收 |
|---|---|---|
| F2a | 新 renderer 应用骨架多页入口（app.html）+ theme TS 范本 + ipc-client 范本 + `OP_DESKTOP_NEW_UI` 门控（默认关，flag 开时加载 app 页） | typecheck / build（双页产物）/ test 全绿；默认路径 `desktop:smoke` 不变；`OP_DESKTOP_NEW_UI=1` 冒烟加载 app 页并确认 React 挂载 |
| F2b | api 通道封装扩展：status/线程/运行等通道族类型对齐 `shared/protocol`，通道清单与 event-registry 对账 | 通道族类型编译通过；清单对账无缺漏 |
| F3 | chat 域逐组件迁移（对话流核心链路，依赖 F1 的 event-display/run-trace/run-display-projection/stream-budget 等） | chat 主流程在新 UI 走通（发消息/流式/事件渲染/审批/终止），事件协议 diff 为空 |
| B6 | agent/pi 域 TS 化，自小到大：approval-policy → subagent-orchestrator → pi-config/pi-runtime/pi-network-proxy → context/write-coordination → agent.mjs 收尾 | 该域回归通过；双形态冒烟（新 UI 走 IPC、旧 client 走 legacy-http） |

## 风险对策（方案 §7）

- agent 域重构引入核心链路回归：B6 模块自小到大、逐模块对拍/回归，agent.mjs 巨物最后收尾；迁移期冻结该域新功能
- SSE → IPC 隐性差异：stream-budget 逻辑已 TS 化（F1），推送前 schema 校验（R2 event-registry）
- Pi SDK 无类型：自补 .d.ts 独立维护
