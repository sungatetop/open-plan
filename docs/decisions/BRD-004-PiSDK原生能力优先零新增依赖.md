# BRD-004 Pi SDK 原生能力优先，零新增依赖

- 状态：已定稿（2026-10-15，U1-U11 交付）
- 出处：`docs/plans/2026-10-15-PI-SDK原生能力优化方案.md` 及交付说明

## 背景

提升首字延迟与会话稳定性时面临"引入新依赖/自研层"还是"深挖 SDK 现有导出"的选择。逆向发现 SDK 导出面远大于实际使用面：会话树分支、上下文精确预算、工具拦截、steering 等原生已提供。

## 决策

1. U1-U11 全部基于 Pi SDK 原生能力实现，**零新增第三方依赖**。
2. 首字提速采用会话预热 + 上下文预算精算（4.6s → 0.4s）。
3. 工具拦截/审批优先用 SDK 原生钩子，不自研中间层。

## 后果

- 正面：无依赖膨胀，升级风险低；SDK 能力随版本升级自动受益。
- 代价：部分能力受 SDK 实现细节约束，需跟随 SDK 版本验证。
- 遗留：flag 开启态端到端实测建议在下一轮真实任务观察（见后续计划）。
