# BRD-005 事件注册表统一治理

- 状态：已定稿（2026-09-24 起建设，v0.11 持续强化）
- 出处：`变更日志.md` v0.9.x-v0.11.x 事件条目、`server/event-registry.mjs`

## 背景

SSE 事件在前后端各自演进，出现过命名漂移、负载不一致、前端消费未知事件等问题；新增事件无准入门槛。

## 决策

1. 所有 SSE 事件必须在 `server/event-registry.mjs` **先注册再使用**（名称/负载 schema/语义），当前 115 种。
2. 后端发送与前端消费都以注册表为唯一协议事实；前端 `event-display.js` 按注册表映射展示形态（图标/类别/文案）。
3. `scripts/event-registry-test.mjs` 一致性回归纳入 CI，守护注册表不被静默破坏。
4. 未知事件前端安全忽略（向后兼容）。

## 后果

- 正面：协议漂移被测试拦截；事件目录即协议文档。
- 代价：新增事件多一道注册步骤。

## 现状

- 已生效：115 种事件全量注册；Qoder 事件 schema 覆盖批次进一步完善负载描述。
