# GIS G3 · 高德地图 MCP 桥接入指南

> 交付批次：GIS 交付层（批次 4/5）· G3
> 功能开关：`OAW_AMAP_MCP_BRIDGE`（默认关闭；开启后生效，关闭 = 完全回到既有基线）

## 1. 能力说明

接入高德 MCP Server（Streamable HTTP）后，Agent 在对话中即获得高德的地理编码 / 逆编码 / POI 搜索 / 路线规划等工具，结果可由 Agent 直接经 `map_import` 转成地图图层或写入报告。

- 接入基础设施 100% 复用既有 MCP 管理器（`server/mcp管理.mjs` + 集成中心 UI），核心链路零改动。
- 唯一的协议适配：高德官方接入契约要求把 Key 放在 URL 查询参数（`https://mcp.amap.com/mcp?key=...`），
  而本系统的通用安全规则是「凭据一律走 HTTP 请求头、不进 URL」。因此新增了**定向豁免**：
  仅当主机为 `mcp.amap.com` 且功能开关开启时，允许 `key` 型查询参数；其余端点规则不变，
  URL userinfo（`user:pass@`）在任何情况下仍然拒绝。

## 2. 开启方式（服务端）

任选其一：

- 启动服务前设置环境变量：`set OAW_AMAP_MCP_BRIDGE=1`（Windows）或 `export OAW_AMAP_MCP_BRIDGE=1`；
- 或在既有启动脚本 / `.env` 管道中加入该变量。开关状态可在 `/api/status` 的 `runtimeFlags.amapMcpBridge` 核对。

## 3. 配置步骤（界面）

1. 打开「集成中心 → MCP」；
2. 点击表单区右上角新增的 **「高德地图预置」** 按钮（仅开关开启时显示）——自动填入：
   - 服务名称：`高德地图 MCP`
   - 传输方式：`Streamable HTTP`
   - 服务地址：`https://mcp.amap.com/mcp`
3. 在「高德开放平台 → 控制台 → 应用管理 → 我的应用」创建/选择一个 **Web 服务** 类型 Key，
   把服务地址补全为 `https://mcp.amap.com/mcp?key=你的Key`；
4. 点击「保存 MCP 配置」（保存后默认停用，符合既有安全基线）；
5. 点击该服务的 **「测试并读取工具」**，连通成功会列出工具清单（geocode / regeo / text / around / route 等）；
6. 确认工具无误后 **启用** 该服务。启用只影响**新建会话**（既有会话的工具集不变）。

## 4. Agent 侧使用

新会话中 Agent 会自动看到高德工具。典型指令示例：

- 「查一下杭州市余杭区的经纬度」（geocode）
- 「搜杭州东站周边 1km 的停车场，标到地图上」（POI → 结果转 `map_import` 图层）
- 「规划义乌 → 金华的驾车路线，画在地图上」（路线 → 线图层）

工具调用是否需要审批，沿用既有审批策略（未标注只读的工具会按策略请求确认）。

## 5. 安全说明

- Key 以明文保存在本机 `APP_DATA_DIR/集成/mcp-servers.json`（与其它 MCP 凭据同等待遇，不出本机）；
- 服务端报错路径已有凭据脱敏（`redactServerError`：env/headers 值不会出现在错误信息里）；
- Key 在 URL 中意味着它可能出现在本地浏览器地址栏与代理日志里——这是高德官方协议的固有限制，
  建议为该 Key 单独配置额度并按需轮换（高德控制台支持 Key 删除重建）；
- 撤销接入：集成中心删除该 MCP 配置即可，无需改代码。
