## 3. 设计要点与边界口径

- **G7 执行器**：专用浏览器会话（不干扰用户面板）；open → resize 到目标尺寸 → 视口稳定后建图（导出视图内置稳定性等待）→ 轮询 `__OAW_EXPORT_READY` → PNG 截图 / printToPDF（@page 同尺寸）→ 落工作区 `地图导出/{批次}/`。单时刻仅允许一个批次（409 保护）；任务上限 24，超出记 skipped 不静默丢弃。
- **G2 sql-database**：node:sqlite readOnly 打开 + 子查询包 LIMIT 50000 + 写关键词整词拒绝 + 多语句拒绝 + 工作区边界校验（path.relative 判目录穿越）。
- **G3 豁免范围**：仅 `mcp.amap.com` 主机 + flag 开启时允许 `key` 型 query；`user:pass@` 形式任何情况拒绝；文档明示 Key 落本机与轮换建议。
- **G9 恢复口径**：zip 内布局 = 项目目录布局；瓦片默认只带索引（可由图层重建），`tiles=1` 携带本体（≤256MB 超限报 413）。
- **G5-v1 简化声明**：v1 为确定性编排（未走编辑流水线 Planner→Writer→Evaluator 完整范式），仅 od-commuter 一个模板；G6 向导 / G5 其余两模板未动。
- **产物进成果管理的口径差异**：G7/G8/G5 产物落工作区（`地图导出/`、根目录 docx），可查可下载；既有成果管理 publishArtifact 需要 runId 关联，批量导出无 Run 上下文，故未强制走 publish/acceptance 流程（已在验收标准中如实对齐为"产物可查"）。

## 4. 已知限制与后续项

1. `PI迭代全链路测试.mjs --live` 在本机曾因 Agent 冷启动漂移（~100s+）出现 capability_plan 120s 等待超时——属既有环境问题，与本批次无关（本批次未触碰 Pi 运行时链路）；该脚本自身等待窗口可另行放宽。
2. 可视面板对 live-traffic-api / sql-database 暂无参数输入 UI（url/db/sql 经 Agent 或 HTTP 参数使用），后续可加向导。
3. G5 剩余两模板（设施可达性、路网结构诊断）、G6 专题图向导、G11 时间轴动画、B6~B10 浏览器能力、P 系列剩余打磨项未在本批次范围。
4. 地图性能基线目前为本地脚本（test:map-perf），未来接 CI 时直接采集 PERF-BASELINE JSON 行。
