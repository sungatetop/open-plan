## 一、评审方法

- 静态全量扫描：emoji 使用、原生 `alert/confirm`、自研弹窗（backdrop/overlay）、`Escape` 键处理、`aria-label`、`disabled` 异步防护、`@media` 响应式断点、图标体系引用分布；
- 链路走查：会话管理、对话提交、产物打开、设置变更、知识库操作、地图项目操作等高频路径的反馈方式与状态流转；
- 图标体系专项：[Icon.jsx](file:///f:/Claude%20code本地文件/office-agent-web/client/src/components/Icon.jsx)、[ProviderIcon](file:///f:/Claude%20code本地文件/office-agent-web/client/src/components/Icon.jsx#L189-L208)、[工具语义图标.jsx](file:///f:/Claude%20code本地文件/office-agent-web/client/src/components/工具语义图标.jsx) 三套图形源的口径核对。

## 二、体系现状（先说亮点）

1. **图标基座质量高**：[Icon.jsx](file:///f:/Claude%20code本地文件/office-agent-web/client/src/components/Icon.jsx) 统一线性 SVG（stroke 风格、统一 `viewBox`/`strokeWidth`/圆角端点，约 70 个命名图标），未注册名称在 DEV 下一次性告警并可定位补注册位置，`aria-hidden="true"` 默认无障碍处理正确。
2. **品牌图形零外链**：`ProviderIcon` 全部内联 simple-icons（CC0）矢量，无 CDN/远程图片请求，避免模型列表出现空白图标。
3. **异步防护覆盖广**：`disabled={...}` 全项目 129 处、24 个文件，多数提交类按钮具备防重复点击能力。
4. **响应式有基础**：[styles.css](file:///f:/Claude%20code本地文件/office-agent-web/client/src/styles.css) 内 23 个 `@media` 断点。
5. **Emoji 未侵入生产 UI**：emoji 扫描仅命中原型页 [桌面端Agent原型.jsx](file:///f:/Claude%20code本地文件/office-agent-web/client/src/components/桌面端Agent原型.jsx)（`?prototype=desktop` 才挂载）。

## 三、问题清单（按优先级排序）

### P0 — 阻断「体验一致性」的结构性问题

#### P0-1　全局反馈依赖原生 `alert()/confirm()`，共约 60 处、12 个文件
- **现象**：错误提示、删除确认、风险确认全部走浏览器原生弹窗。分布：[App.jsx](file:///f:/Claude%20code本地文件/office-agent-web/client/src/App.jsx)（5）、[ChatPanel.jsx](file:///f:/Claude%20code本地文件/office-agent-web/client/src/components/ChatPanel.jsx)（6）、[SessionSidebar.jsx](file:///f:/Claude%20code本地文件/office-agent-web/client/src/components/SessionSidebar.jsx)（15+）、[SettingsPanel.jsx](file:///f:/Claude%20code本地文件/office-agent-web/client/src/components/SettingsPanel.jsx)（8）、[KnowledgeBase.jsx](file:///f:/Claude%20code本地文件/office-agent-web/client/src/components/KnowledgeBase.jsx)（9）、[IntegrationsCenter.jsx](file:///f:/Claude%20code本地文件/office-agent-web/client/src/components/IntegrationsCenter.jsx)（5）、[MapPanel.jsx](file:///f:/Claude%20code本地文件/office-agent-web/client/src/components/MapPanel.jsx)（3）、[FileSidebar.jsx](file:///f:/Claude%20code本地文件/office-agent-web/client/src/components/FileSidebar.jsx)、[FileChangesPanel.jsx](file:///f:/Claude%20code本地文件/office-agent-web/client/src/components/FileChangesPanel.jsx)、[AgentMarket.jsx](file:///f:/Claude%20code本地文件/office-agent-web/client/src/components/AgentMarket.jsx)、[DocViewer.jsx](file:///f:/Claude%20code本地文件/office-agent-web/client/src/components/DocViewer.jsx)、[ImageViewer.jsx](file:///f:/Claude%20code本地文件/office-agent-web/client/src/components/ImageViewer.jsx)。
- **影响**：阻塞主线程（动画冻结）、与暗色主题割裂、窗口不可定制、多会话并行操作时打断其它面板的进行中反馈，是当前「精致度」最大扣分项。
- **建议**：新建统一反馈基座 `FeedbackProvider`：
  - `toast(message, {tone})` 队列式轻提示（成功/失败/警告三态，右下角，自动消退，可手动关闭）；
  - `confirmDialog({title, body, danger})` 返回 Promise 的应用内确认框（支持 Esc/Enter 快捷键、danger 态红色主按钮）；
  - 逐文件机械替换 60 处调用点，先行替换 SessionSidebar/SettingsPanel/KnowledgeBase 三个高频文件。

#### P0-2　弹窗/浮层实现碎片化：7 处自研 backdrop/overlay，无统一 Modal 基座
- **现象**：`backdrop|overlay` 命中 58 处、9 个文件——[SessionSidebar.jsx](file:///f:/Claude%20code本地文件/office-agent-web/client/src/components/SessionSidebar.jsx#L1025-L1133)（产物/设置/历史 3 类自研弹窗，`sb-modal-backdrop`）、[MapPanel.jsx](file:///f:/Claude%20code本地文件/office-agent-web/client/src/components/MapPanel.jsx)（8 处 overlay）、[AgentMarket.jsx](file:///f:/Claude%20code本地文件/office-agent-web/client/src/components/AgentMarket.jsx)、[CommandPalette.jsx](file:///f:/Claude%20code本地文件/office-agent-web/client/src/components/CommandPalette.jsx)、[AttributeTable.jsx](file:///f:/Claude%20code本地文件/office-agent-web/client/src/components/AttributeTable.jsx)、[SkillsManager.jsx](file:///f:/Claude%20code本地文件/office-agent-web/client/src/components/SkillsManager.jsx)、[供应商库.jsx](file:///f:/Claude%20code本地文件/office-agent-web/client/src/components/供应商库.jsx)、[TemplateLibrary.jsx](file:///f:/Claude%20code本地文件/office-agent-web/client/src/components/TemplateLibrary.jsx) 各 1 处。
- **影响**：层级（z-index）互相踩踏风险、遮罩样式与动画不一致、键盘行为不统一——`Escape` 处理仅 18 处、11 个文件，部分弹窗只支持点击遮罩关闭，不支持 Esc。
- **建议**：抽 `Modal` 基座组件（遮罩 + Esc 关闭 + 点击遮罩关闭 + 焦点圈闭 + 统一进出场动画），SessionSidebar 三类弹窗与 MapPanel overlay 优先迁移；CommandPalette 已有最完整键盘体验，以其为行为基准。

### P1 — 明显影响使用体验与视觉统一

#### P1-1　行内状态提示仅 2 个组件具备，操作成功普遍「无感」
- **现象**：`setNotice/setHint` 类行内反馈仅 [IntegrationsCenter.jsx](file:///f:/Claude%20code本地文件/office-agent-web/client/src/components/IntegrationsCenter.jsx)（19）与 [TemplateLibrary.jsx](file:///f:/Claude%20code本地文件/office-agent-web/client/src/components/TemplateLibrary.jsx)（13）实现；其余模块操作成功后无任何提示（如导出成功走 `alert`）。
- **建议**：成功类反馈统一走 P0-1 的 `toast`（success 态），失败类优先行内红字（表单场景）+ toast 兜底（非表单场景）。

#### P1-2　桌面原型页被静态引入主 bundle，且自带独立 toast/emoji 体系
- **现象**：[main.jsx](file:///f:/Claude%20code本地文件/office-agent-web/client/src/main.jsx#L20-L25) 静态 `import DesktopAgentPrototype`，仅 `?prototype=desktop` 时渲染，但代码与 [桌面端Agent原型.css](file:///f:/Claude%20code本地文件/office-agent-web/client/src/components/桌面端Agent原型.css)（含 `dp-toast` 独立 toast、emoji 图标）始终打进主包。
- **影响**：生产 bundle 无效体积；两套 toast/图标体系并存造成口径混乱。
- **建议**：改 `React.lazy(() => import(...))` 按需加载；原型定位为设计稿演示页，标注「不进生产交付验收范围」。

#### P1-3　三套图形源并存，缺统一「尺寸栅格 + 色彩口径」约定
- **现象**：`Icon`（stroke 线性）/ `ProviderIcon`（fill 品牌面性）/ `ToolIdentityIcon`（工具语义）并存。`Icon` 调用处 `size` 取值 10/11/12/13/14/16 混杂（如 [SessionSidebar.jsx](file:///f:/Claude%20code本地文件/office-agent-web/client/src/components/SessionSidebar.jsx#L883) 用 11），视觉密度不一致。
- **建议**：成文规范——功能图标只允许 `12/14/16` 三档，行内嵌字 12、按钮 14、标题/空态 16；品牌面性图标固定 14 并与线性图标基线对齐；`ToolIdentityIcon` 色彩只允许 `var(--dim)/var(--accent)` 两档。

#### P1-4　`aria-label` 覆盖不均，部分图标按钮纯视觉无语义
- **现象**：全项目 91 处 `aria-label` 分布不均——[MapPanel.jsx](file:///f:/Claude%20code本地文件/office-agent-web/client/src/components/MapPanel.jsx) 8 处 overlay 仅 2 处 aria-label，[KnowledgeBase.jsx](file:///f:/Claude%20code本地文件/office-agent-web/client/src/components/KnowledgeBase.jsx) 图标操作密集但仅 2 处，[IntegrationsCenter.jsx](file:///f:/Claude%20code本地文件/office-agent-web/client/src/components/IntegrationsCenter.jsx) 仅 1 处。对照 [SessionSidebar.jsx](file:///f:/Claude%20code本地文件/office-agent-web/client/src/components/SessionSidebar.jsx#L883)（`title` + `aria-label` 双写）为正确范式。
- **建议**：以 SessionSidebar 为基准，图标按钮一律 `title`（悬停提示）+ `aria-label`（读屏）双写；Tab 键可达性与 `:focus-visible` 样式随 Modal 基座一并落地。

### P2 — 打磨项

#### P2-1　确认文案口径不统一
- **现象**：同为删除确认，措辞/标点/风险说明深度不一：`"确认删除此会话?"`（半角问号）、`` `删除 ${name} ?` ``（问号前空格）、详细版带后果说明（如 IntegrationsCenter 的扩展启用确认写明权限风险，是最佳实践）。
- **建议**：成文文案规范：`动作 + 对象 + 后果说明` 三段式，统一中文全角标点；破坏性操作必须写明可逆性（如 MapPanel 的「移入回收目录，不会立即物理删除」即为正确范例）。

#### P2-2　小屏/窄面板适配需专项走查
- **现象**：23 处 `@media` 已有基础，但内置浏览器、工作产物、地图三大面板在 <900px 窄窗口下的工具栏溢出/图标截断未系统验证。
- **建议**：按 1440 / 1200 / 900 / 600 四档窗口宽度走查三面板 + 侧栏 + 设置页，重点检查工具栏图标折叠策略（优先收纳进 `menu` 溢出菜单而非截断）。

#### P2-3　异步失败模式「点击→alert 报错」，前置校验缺位
- **现象**：多处在点击后才发现输入非法（如 [SessionSidebar.jsx](file:///f:/Claude%20code本地文件/office-agent-web/client/src/components/SessionSidebar.jsx#L438) `alert("请输入文件夹路径")`）。
- **建议**：表单类操作改为提交前即时校验 + 输入框行内红字；按钮 `disabled` 时通过 `title` 说明禁用原因。

#### P2-4　Icon 未注册名仅 DEV 运行时告警，缺构建期防线
- **现象**：[Icon.jsx](file:///f:/Claude%20code本地文件/office-agent-web/client/src/components/Icon.jsx#L103-L115) 机制已好，但生产构建静默返回 null，页面只表现为「图标不见」。
- **建议**：Vite 构建期插件（或单测）静态扫描 JSX 中 `<Icon name="...">` 字面量，未注册即构建失败，成本约半天。

## 四、落地路线（三批交付）

| 批次 | 内容 | 验收标准 |
|---|---|---|
| 第一批（P0） | FeedbackProvider（toast + confirmDialog）落地并替换 60 处原生调用；Modal 基座迁移 SessionSidebar + MapPanel | 全项目 grep `alert(/confirm(` 归零；所有弹窗支持 Esc + 遮罩关闭 + 焦点圈闭 |
| 第二批（P1） | 成功反馈补全；原型 lazy 化；图标尺寸栅格收敛为 12/14/16；aria-label 补齐 | 各高频操作均有可感知反馈；主 bundle 不含原型代码；图标按钮 100% 双写 |
| 第三批（P2） | 文案规范成文并统一；四档宽度响应式走查修复；表单前置校验；Icon 构建期断言 | 文案三段式 100% 覆盖；四档宽度无溢出/截断；`<Icon name="未注册">` 可阻断构建 |
