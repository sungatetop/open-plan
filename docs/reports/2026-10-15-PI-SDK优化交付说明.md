## 1. 逐项交付明细（修改内容 / 实现功能 / 测试结果）

### U1 上下文预算治理精确化
- **修改内容**：
  - [Pi运行时管理.mjs](file:///f:/Claude%20code本地文件/office-agent-web/server/Pi运行时管理.mjs)：新增 `getContextUsage()` 透传（agent-session.d.ts L874）与 `contextTokensFromUsage()` 导出（包装 SDK `calculateContextTokens`，容错返回 null）；
  - [agent.mjs](file:///f:/Claude%20code本地文件/office-agent-web/server/agent.mjs)：`emitUsage` 的 stats 事件附带 `contextUsage`/`contextTokens`（**长名→短名形状适配**：SDK 期望 `input/output/cacheRead/cacheWrite`）；`agent_turn_end` 发独立 `context_usage` 事件（低频不落盘）；`_maybeCompact` 压缩决策优先使用精确值，取不到回落既有估算（fallback 行为不变）；
  - [事件注册表.mjs](file:///f:/Claude%20code本地文件/office-agent-web/server/事件注册表.mjs)：登记 `context_usage`（persist:false）。
- **实现功能**：上下文计量从"字符估算+usage 加总"升级为 Pi SDK 实测精确值；压缩触发与真实窗口对齐。
- **测试结果**：✓ 4 条断言通过（null 容错 / 短名计算 120 与 totalTokens 优先 77 / getContextUsage 透传与兜底）。**实现过程中发现并修复形状适配缺陷**：首版直接传长名 usage 导致计算恒 null——验收脚本捕获后已修复（这正是验收脚本的价值）。

### U2 工具把关流水线（单工具级硬拦截）
- **修改内容**：新增 [server/pi-extensions/工作台把关.mjs](file:///f:/Claude%20code本地文件/office-agent-web/server/pi-extensions/工作台把关.mjs)（ExtensionFactory：`tool_call` 拦截 + `turn_start`/`tool_result` 状态维护 + `session_before_compact`/`session_compact_failed`）；agent.mjs 经 `additionalExtensionPaths` 按 flag 加载；`tool_execution_end` 转译检测 `[工具门禁]` 标记发 `tool_gate_denied`（persist:true）；扩展自持会话内预算状态（复用 运行预算.mjs 纯函数），与 E02 事件层门禁分层（扩展=工具级拦截、E02=回合级硬停）。
- **实现功能**：硬预算/连续失败命中时**只拒绝单个工具调用**（block + 结构化 reason，模型可调整方案继续），不再像 hard 模式那样整 Run 中断。
- **测试结果**：✓ 5 条断言通过（工厂形状 / 标记检测 / 事件注册完整 / 正常调用不拦截 / **同一操作连续失败两次后 block**——按运行预算门禁语义触发）。

### U3 原生会话树分支与导航
- **修改内容**：Pi运行时管理.mjs 新增 `getSessionTree()`（session-manager.d.ts L340 `getTree()`）与 `navigateSessionTree()`（agent-session.d.ts L850 `navigateTree(targetId,{summarize,label})`）；`runtimeCapabilities.nativeFork` **reserved → available**；agent.mjs 主会话创建解构并保存 `sessionManager` 到 entry + 新增 `sessionTree()/branchSession()` 类方法（busy 拒绝导航）；index.mjs 新增 `GET /api/agent/session-tree`、`POST /api/agent/session-branch`；runs.mjs `beginRun` 新增 `branchOfRunId/branchPointEntryId` 可选字段（向后兼容）。
- **实现功能**：会话级"回退/分支切换"——导航到历史节点后下一次 prompt 在目标分支继续，被弃分支由 Pi 原生 `generateBranchSummary` 生成摘要；S5 缺口关闭。
- **测试结果**：✓ 6 条断言通过（capabilities 升级 / getTree 透传 / navigateTree 透传与选项 / 不支持时明确报错 / 类方法存在 / 端点存在）+ **运行时验证**：新进程 `GET /api/agent/session-tree` 返回 `nodeCount=1, hasSessionFile=true`。

### U4 bash 命令门禁统一事件
- **修改内容**：agent.mjs bash `operations.exec` 的两处前置拒绝（`BASH_SCOPE_BLOCKED` 全盘搜索、`MEMORY_WRITE_REQUIRES_PROPOSAL` 记忆保护）在既有 `write_rejected` 之外统一补发 `tool_gate_denied`。
- **实现功能**：命令级门禁拒绝进入统一事件语义（与 U2 扩展拦截同类型），跨会话回放可审计。现状澄清：项目 bash 已通过自定义 `operations.exec` 实现 spawn 前拦截（U4 方案的"前移"目标此前已达成），本项落地为判定事件的统一化。
- **测试结果**：✓ 1 条断言通过（两处拒绝点均含 tool_gate_denied 发射）。

### U5 内核侧车（bash 进程隔离执行）
- **修改内容**：新增 [server/内核侧车.mjs](file:///f:/Claude%20code本地文件/office-agent-web/server/内核侧车.mjs)（`BashSidecarManager`：独立进程 spawn 执行、并发上限 4、超时强杀、total/failed/timeout/耗时统计、`getBashSidecar()` 共享实例）；agent.mjs bash exec 在 `OAW_PI_SIDECAR=on` 时经侧车执行，off（默认）走 `createLocalBashOperations` 原路径。
- **实现功能**：bash 执行获得统一管理面（隔离进程 + 并发保护 + 执行统计）；评审 R6 缩水路径的"侧车基建"部分（为 DSH C1 侧车提供同构管理器）。**诚实边界**：非常驻 RPC 子进程形态（SDK RPC 无 customTools 注册命令，静态 No-Go）。
- **测试结果**：✓ 4 条断言通过（真实命令执行与结构化结果 / 统计累计 / **超时强杀标记 killed** / 共享实例）。

### U6 压缩生命周期事件
- **修改内容**：注册表登记 `compaction_failed`（persist:true）；agent.mjs `_maybeCompact` catch 处补发 `compaction_failed`（与既有 `context_compact_warning` 并行）；`context_compacting/context_compacted` 加入 emit 的 recordRunEvent 白名单（落盘回放）。现状澄清：`compaction_start/end` 转译（`context_compacting/compacted`）此前已存在，本项增量收敛为**失败可见化 + 持久化补全**。
- **实现功能**：压缩失败不再静默（此前 SDK 自动压缩失败只在溢出重试路径间接体现），跨会话回放可审计。
- **测试结果**：✓ 2 条断言通过（注册表登记 / 发射点存在）。

### U7 消息投递语义规范
- **修改内容**：agent.mjs 轮次提醒分流——`turn-budget` 类（软轮次提醒）改用 `session.followUp()`（工具链收尾后投递，不打断进行中工具执行）；周期进度与硬轮次保持 `steer`；index.mjs `/api/agent/pending` 暴露 `pendingMessages`（SDK `pendingMessageCount`，评审 R9 修正后的真实 API）。
- **实现功能**：预算提醒不再插队打断工具执行；待投递消息数量可观测（前端徽标数据源就绪）。
- **测试结果**：✓ 2 条断言通过（followUp 分流 / pendingMessageCount 暴露）+ **运行时验证**：`/api/agent/pending` 返回 `pendingMessages=0`。

### U8 事件规范化层
- **修改内容**：新增 [server/事件规范化.mjs](file:///f:/Claude%20code本地文件/office-agent-web/server/事件规范化.mjs)（`CANONICAL_SCHEMA_VERSION`、`PI_EVENT_TO_CANONICAL` 映射表 17 项、`normalizePiEvent`/`canonicalFromEnvelope`/`assertCanonicalShape` 纯函数）；agent.mjs emit 在 `OAW_EVENT_NORMALIZE=on` 时给信封挂 `canonical` 视图（**内存态，不落盘、SSE 契约形状零改动**）；EventBus 未引入（评审 R10：8 行 pub/sub 价值有限，多订阅者需求出现时再加）。
- **实现功能**：事件转换从内联 switch 升级为可测试纯函数；第二阶段 DSH 适配可直接复用 schema 与 `assertCanonicalShape`（`normalizeDshEvent` 的对偶）。
- **测试结果**：✓ 4 条断言通过（映射 / 未知类型保守透传 / 信封转换含 runId / 形状断言抛错）。

### U9 项目信任薄封装
- **修改内容**：新增 [server/项目信任.mjs](file:///f:/Claude%20code本地文件/office-agent-web/server/项目信任.mjs)（`ProjectTrustStore` 单例 + `workspaceTrustDecision` 三态 + `workspaceRequiresTrustGate` + `workspaceTrustSummary` + `setWorkspaceTrust` flag 门禁）；index.mjs 新增 `GET/POST /api/agent/workspace-trust`（GET 只读诊断始终可用；POST 需 `OAW_PROJECT_TRUST_GATE=on`）。
- **实现功能**："首次打开工作区"信任判定接入 SDK 原生信任位（三态 boolean|null，评审 R9 收敛：不做多级映射）；运行时验证已检测到工作区存在需门禁资源（`requiresGate=true`）。
- **测试结果**：✓ 2 条断言通过（summary 形状 / flag off 时写入拒绝 fail-safe）+ **运行时验证**：端点返回 `requiresGate=True, flagEnabled=False`。

### U10 供应商提示词缓存保活
- **修改内容**：能力面结论（cache-warmer.d.ts 实证）：CacheWarmer 由 SettingsManager 原生 `cacheWarming` 模式驱动（`CACHE_WARMING_MODES=["off","streaming","idle"]`）——**从"spike 决定去留"升级为配置级落地**：Pi运行时管理.mjs `SettingsManager.inMemory` 在 `OAW_CACHE_WARMING=on` 时配置 `cacheWarming:"streaming"`（Run 进行中 1-token 请求保活缓存）；运行开关.mjs 新增该 flag 并入快照。
- **实现功能**：用户思考/审批期间提示词缓存不失效，下一请求省去全量 cache miss 重算（延迟与费用双降）；off（默认）行为不变。
- **测试结果**：✓ 2 条断言通过（flag 默认 off / 条件配置存在）。

### U11 工具组工厂标准化（能力验证 + 评估结论）
- **修改内容**：无生产代码改动（评审后决策）。验证 `createReadOnlyTools` 实际产出（4 只读工具 read/grep/find/ls 形状完整）；确认子代理 scout 的 grep/find/ls 已由 SDK 内置组经工具白名单激活、`childReadTool` 为 managed 版（写锁/事件追踪增强）。
- **实现功能/结论**：**替换不采纳**——managed 工具的审批与写锁是项目安全增强，SDK 原生只读组无此能力；SDK 工厂作为能力基线保留在验收脚本中持续校验。
- **测试结果**：✓ 2 条断言通过（SDK 工厂产出形状 / 子代理 managed 路径未被误改）。
